# WASD brand kit

House mark for fetch it. Hex + WASD keys, black and white only.

| Token | Hex       | Use                    |
|-------|-----------|------------------------|
| ink   | `#000000` | window, hex fill       |
| paper | `#FFFFFF` | borders, type, mark    |

Copy `WasdMark.cs` and `CutCornerFrame.cs` into other WASD apps.
